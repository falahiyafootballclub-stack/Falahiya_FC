FALAHIYA FC WEBSITE — STARTER PACKAGE

Files:
- index.html: homepage and page sections
- styles.css: responsive blue-and-white design
- script.js: mobile navigation and current year
- assets/falahiya-fc-crest.png: crest provided by the club

HOW TO PREVIEW
Open index.html in a web browser. Internet access is needed to load the Google Fonts; the rest of the site is local.

HOW TO PUBLISH FOR FREE (GitHub Pages)
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. falahiya-fc-website.
3. Upload index.html, styles.css, script.js and the assets folder (keep the same structure).
4. In the repository, open Settings → Pages.
5. Select deployment from the main branch and root folder, then save.
6. GitHub will provide a public website address after deployment.

BEFORE PUBLICATION
- Confirm club history, founding year, stadium, competition, honours and all public contact details.
- Add only player names/photos approved for publication.
- Update the squad, fixtures, results and honours sections with verified details.
- The JSON-LD uses SportsOrganization markup and is a helpful signal, not a guarantee of Google results or a Knowledge Panel.
- After publication, add the live website to Google Search Console, verify ownership, submit the sitemap if one is added, and request indexing for key pages.
- Google indexing and Knowledge Panel display are not guaranteed or immediate.
